新增 Emby 节点

基础设置

通常只需要填写名称、短路径和上游地址。

高级设置 一般保持默认即可

获授权的客户端兼容

仅用于你拥有或已获授权的上游。开启后只会补充/覆盖 User-Agent 与 X-Emby-Client 等提示请求头，方便你自建服务器按客户端做兼容处理；不会改写登录凭据、令牌或播放器上报的真实身份，因此不会影响播放。它不是用来隐藏真实播放器或绕过上游的设备限制/反代限制的。

选择一个客户端身份模板快速填充，或在下方手动微调。

推流网址反代

少数 Emby 服务器登录和播放用的是两个不同网址（前后端分离）。开启后，播放也会走你的反代域名、不直连原服务器。不清楚就保持关闭；仅用于你自己拥有或已获授权的服务器。

自动切流

这台节点的播放变慢时，自动把取流请求切到另一台机器（还需在「自动切流」页面打开总开关）。上游会看到来源 IP 在播放中途变化，只在不会因此封号的上游上开启。限速节点不能开启。

分发通道（多用户）

给同一个 Emby 节点生成多把带标签的连接密码，每把 = 一个用户的专属链接（同别名不同密码）。可单独删除某个用户而不影响其他人；“访问监控”会按通道分别统计谁在看、谁把链接转分发了。需先启用连接密码。
